# Personal Portfolio

A lightweight portfolio website for GitHub Pages.

## Customize

1. Edit `index.html` to update your introduction, skills, and contact links.
2. Add your résumé PDF to the same folder as `index.html` and name it `resume.pdf`.
3. Optionally change the accent color in `style.css` (`--accent`).

## Publish with GitHub Pages

1. Create a public repository on GitHub (for example `portfolio`).
2. Upload the contents of this folder to the root of the repository.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.
5. Your site will appear at `https://YOUR-USERNAME.github.io/portfolio/` after GitHub finishes deploying.

If your repository is named `YOUR-USERNAME.github.io`, the URL is `https://YOUR-USERNAME.github.io/` instead.
